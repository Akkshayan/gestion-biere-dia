# StockBiere - DIAGO

Outil interne de gestion de stock en temps reel pour le rayon bieres de DIAGO (Bois-Colombes).

## Prerequis

- Node.js version 18 ou superieure (inclut npm)
- Un acces a une base PostgreSQL (locale pour les tests)
- Visual Studio Code (ou tout autre editeur)
